# Trabajar con esta skill

Lee README.md y skills/requerimientos-socraticos/SKILL.md antes de usarla.
Los comandos `gentle-ai requirements` describen una extensión local del entorno
original. Esta distribución conserva sus fuentes; si no dispones de esa extensión,
usa los helpers Python equivalentes indicados en README, con intérprete explícito.
No instales dependencias ni ejecutes ensayos de carga automáticamente.
El sondeo solo observa el entorno visible; no garantiza capacidad física del host.
Respeta las decisiones humanas, el alcance y los permisos de todas las plataformas.
